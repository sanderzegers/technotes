# Choosing the Right Python Data Type

| Type        | Use when you need…                                   | Example                         | Key property                                   |
| ----------- | ---------------------------------------------------- | ------------------------------- | ---------------------------------------------- |
| **`list`**  | An ordered collection that can change                | `["apple", "banana", "pear"]`   | Ordered, mutable, allows duplicates            |
| **`tuple`** | An ordered collection that should stay fixed         | `(10, 20)`                      | Ordered, immutable, allows duplicates          |
| **`set`**   | Unique values and fast membership checks             | `{"admin", "user"}`             | Unordered, mutable, no duplicates              |
| **`dict`**  | Key → value relationships                            | `{"name": "Anna", "age": 25}`   | Keyed lookup, mutable                          |
| **`class`** | Data represents a thing with attributes and behavior | `user`,`employee`,`BankAccount` | Bundles data and methods into reusable objects |
| **`enum`**  | One value from a fixed set of named choices          | `FirewallAddressType.SUBNET`    | Fixed set of named values.                     |

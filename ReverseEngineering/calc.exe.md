# Calc

### General

|          |                           |
| -------- | ------------------------- |
| Alt + 1  | Standard Mode             |
| Alt + 4  | Programmer Mode           |
|          |                           |
| CTRL + M | MS (Store to memory)      |
| CTRL + P | M+ (Add to memory)        |
| CTRL + Q | M- (Subtract from memory) |
| CTRL + R | MR (Recall from memory)   |
| CTRL + L | MC (Clear memory)         |
